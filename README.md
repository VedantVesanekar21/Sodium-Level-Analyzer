# Sodium-Level-Analyzer

A web-based Sodium Level Analyzer built with Python, Flask, HTML, and CSS, featuring a simple and user-friendly interface for analyzing sodium levels.

## Features

* Analyze sodium level data
* Display analysis results through a user-friendly interface
* Simple and intuitive web interface
* Built using Flask for backend processing
* Responsive design using HTML and CSS

## Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/VedantVesanekar21/Sodium-Level-Analyzer.git
   ```
2. Navigate to the project folder:

   ```bash
   cd Sodium-Level-Analyzer
   ```
3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:

   ```bash
   python app.py
   ```
5. Open your browser and visit:
   `http://127.0.0.1:5000`

## Technologies Used

* Python
